# Atlyss_Brutaliser
This tool is for removing unneeded files from an Atlyss mod directory specifically for dedicated server hosting. 
The files removed includes textures, meshes, lua files, and files left over from modders that are not actually used, and more.

### How to use:
Place Brutaliser.bat into your BepInEx folder next to your plugins folder (...\profiles\PROFILENAME\BepInEx)
Launch the batch file.
Once it is completed the console will pause showing that the work was completed.
This must be done every time a mod update is downloaded

## Currently this tool is not compatible with [Custom Quest mod](https://thunderstore.io/c/atlyss/p/Yavamar/CustomQuests/) and [Prop placer mod](https://thunderstore.io/c/atlyss/p/FireNoobsta/Prop_Placer/). Using this tool deletes all files associated with those mods.
